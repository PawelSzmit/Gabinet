# GabinetPWA

Ten katalog zostaje jako archiwalne zrodlo porownawcze po scaleniu do root `Gabinet`.

Aktualny stan docelowej aplikacji:

- uruchamianie: katalog root projektu,
- shell i PWA assets: root,
- model danych, security, offline i finanse po scaleniu: root.

Nie rozwijaj nowej funkcjonalnosci w `GabinetPWA`, dopoki koncowa reczna weryfikacja nie potwierdzi potrzeby dodatkowego porownania albo odzyskania konkretnego fragmentu.
